현문(玄問) 주역 웹사이트 설치 안내

구성 파일
- index.html : 첫 화면
- style.css  : 디자인
- app.js     : 동전 던지기와 64괘 해석

무료 호스팅에 올리는 방법
1. ZIP 파일을 압축 해제합니다.
2. Netlify Drop, GitHub Pages, Cloudflare Pages 등의 서비스에
   index.html, style.css, app.js 세 파일을 같은 폴더 구조로 업로드합니다.
3. 별도의 서버나 데이터베이스는 필요하지 않습니다.

컴퓨터에서 먼저 확인하려면 index.html을 더블클릭해 브라우저로 여세요.

주의: 파일 이름과 세 파일의 상대적인 위치를 바꾸지 마세요.
